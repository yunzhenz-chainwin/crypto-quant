# 訊號成績單分析(2026-06-29)

> 目的:檢驗目前的 6 因子訊號(信心分數 ≥65 偏多 / ≤35 偏空)**到底有沒有預測力**。
> 重跑指令:`python src/signal_scorecard.py`(唯讀,不改任何資料)

## 方法(無偷看未來)
- 每次訊號**首次出現**(onset)那天 `i`,訊號於收盤可知 → **隔天 `open[i+1]` 進場**。
- `N` 天後以 `open[i+1+N]` 結算報酬。
- **偏多**算「之後上漲」為命中;**偏空**算「之後下跌」為命中。
- **基準**=任一天進場的同期報酬(代表「躺著抱」)。
- 跳過暖身期 `SKIP=200`(MA200 需 200 天);15 個幣、約 3,800 個訊號。

## 結果(15 幣彙總)

略為正向但很小:ETH +1.5pp、ADA +1.4pp、SOL +0.7pp、NEAR +0.5pp。

## 結論
- **目前訊號沒有 forward edge。** 偏多訊號剛出現時進場,各持有期(5/10/20 天)命中率**一致地略低於**「任一天進場」的基準(偏多甚至略負)。偏空大致等同基準、無效。1,400+ 樣本,不是雜訊。
- **原因(推測):訊號是「事後確認」型** — RSI 高、MACD 翻正、站上均線等條件湊齊時,漲勢通常已發生,接著容易回檔(輕微均值回歸 / 追高)。
- **不矛盾於回測賺錢**:先前回測看似 OK,主要是 **(1) 大盤整體往上 + (2) 停損/停利在管理部位**,而非進場時機準。**成績單抓到了回測藏起來的真相。**

## 注意(誠實)
- in-sample 歷史統計,**非未來保證**。
- 用 onset(首次出現)而非每天計數,已緩解訊號持續期造成的樣本重疊。
- 基準採「任一天進場」;加密長期偏漲,故基準上漲率仍 <50%(混合多空期間)。

## 後續可試方向(改完重跑 `signal_scorecard.py` 對照 edge)
1. **拉長持有 / 趨勢續抱**(短線回檔,中長線可能跟趨勢)。
2. **加「市場狀態(regime)」過濾**:只在趨勢盤聽訊號、盤整盤不聽。
3. **改門檻或反向思考**(目前 ≥65 像在追高)。
4. **分幣處理**:XRP/LINK/DOT/ATOM/UNI 特別差。

> 產品含義:在訊號做出真正 edge 之前,**不宜把「成績單」當主打對外宣傳**;先當內部研發工具。等 edge 起來,再變成公開的信任武器。
