# 訊號改良實驗（2026-06-30）

> 延續 [訊號成績單分析](訊號成績單分析.md)（現行 6 因子訊號無 forward edge），
> 並排測試 6 個「改良變體」到底有沒有把 edge 做出來。
> 重跑：`python src/signal_experiments.py`（唯讀，不改資料）

## 方法（與成績單同一把尺，無偷看未來）
- 變體於第 i 天收盤可知 → 隔天 `open[i+1]` 進場 → N 天後 `open[i+1+N]` 結算。
- 只取「首次出現(onset)」進場；基準 = 任一天進場（躺著抱）；跳過暖身 200 天；15 幣彙總。
- **edge = 變體平均報酬 − 基準平均報酬**。要「跨持有期一致為正、且樣本夠」才算數。

## 變體
| 代號 | 規則 | 動機 |
|---|---|---|
| baseline | 現行 BULL（score≥65） | 重現成績單 |
| A_反向 | 把現行 BEAR（score≤35）當買點 | 反向 / 抄底 |
| B1_趨勢過濾 | BULL 且 站上 MA200 且 MA200 上彎 | 只在趨勢盤聽訊號 |
| B2_不追高 | BULL 且 RSI<60 且 布林位置<0.8 | 濾掉已過熱的追高 |
| B3_回檔買 | 站上 MA200 且 RSI<45 且 動能轉上 | 趨勢中買回檔（換進場邏輯） |
| D1_極度恐懼 | 恐懼貪婪 FNG≤20 | 純情緒抄底 |
| D2_BULL恐懼 | BULL 且 FNG≤30 | 訊號搭極端恐懼 |

## 結論
- **沒有任何一個變體 beat 基準。** 多數甚至更差。
- **趨勢/動能過濾（B1、B2）反而最差** → 印證「訊號在追高、之後短線回檔」：站上 MA200 + 多頭排列湊齊時，漲勢多半已走完。
- **反向（A）≈ 基準** → 系統的 BEAR 也沒預測力；不是「反著做就會贏」。
- **買極度恐懼（D1）更差** → 本樣本中極端恐懼多半叢集在下跌段，短線續跌；「買在恐懼」的通俗說法在日線短持有期不成立。
- **B3 回檔買** 5 天命中率最高（50.2%）但平均報酬為負 → 「常常小賺、偶爾大賠」，淨值仍無 edge（除非配很緊的停損，待測）。

## 意義（重要）
- 這是**方法在做它該做的事**：用嚴謹的 forward 檢驗，**省下數週調參、避免上線一個假 edge**。
- **單資產 + 日線 + 經典 TA/情緒，在高流動性幣上沒有可提取的進場 edge** —— 這是效率市場的預期結果，不是 bug。

## 下一步（換維度，不要再調同一類因子）
1. **跨幣動量（cross-sectional）**：把 15 幣排名，做多最強 / 放空最弱。橫斷面動量的 edge 比單資產時序 TA 穩健，且**資料已在手**。← 建議優先
2. **幣圈原生資料**：資金費率 / 未平倉 / 基差 / 鏈上。有文獻支持的 edge，但需新資料源。
3. **重新定位產品價值**：把「風控（相關性 / 部位 / 回撤）＋ 誠實的成績單」當主打信任武器，而非「預測下一步」。entry alpha 是最難的一塊，未必是這產品的價值所在。

> 誠實註記：以上為 in-sample 歷史統計，非未來保證。但「一致地無 edge」在 1,400+ 樣本下不是雜訊。
